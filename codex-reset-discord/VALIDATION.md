# 검증 결과

2026-10-14 한국 날짜 기준, Python 3.11에서 확인했습니다.

| 검증 | 결과 |
|---|---|
| `python -B -m unittest discover` | 36개 통과 |
| `python -m py_compile monitor.py test_monitor.py` | 통과 |
| `python monitor.py --demo` | 가상 예고/완료/초기화권 각 1개 출력, 외부 전송 없음 |
| `python monitor.py` | 실제 공개 API 읽기와 3종 분류 미리보기 성공, 외부 전송/상태 저장 없음 |
| Workflow YAML | 구문 읽기 및 주요 설정 검사 통과 |

테스트는 부정/조건/질문/농담/일반적인 리셋 논의 제외, 서비스 완료 상태 사용, 초기화권 지급 단계, 최초 과거 이력 차단, 같은 항목 단계 변경, 중복 방지, 일부 전송 실패 시 이전 성공 기록 유지, 오래된 피드 차단, 429 재시도 대기, 웹훅 비밀값 로그 방지 등을 검증합니다.

웹훅 연결 테스트 모드도 단위 테스트로 검증했습니다. 모의 전송 1건, 공개 API 조회 없음, 운영 상태 변경 없음을 확인했습니다.

실제 Discord 전송과 GitHub Actions 실행은 아직 검증하지 않았습니다. 사용자 서버의 웹훅과 GitHub 저장소를 연결해야 확인할 수 있습니다. 연결 후 README의 `preview → test → send` 순서로 실행합니다. 최초 `send`는 기준점만 저장하며 공지를 전송하지 않습니다. `test`는 연결 확인용 메시지 1건을 전송합니다.
