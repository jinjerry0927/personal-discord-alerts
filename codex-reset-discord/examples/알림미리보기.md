# Discord 알림 미리보기

아래는 **가상 데이터**로 만든 예시입니다. 실제 신규 리셋 소식이 아닙니다. 세 가지 유형을 한 채널에 색과 제목으로 구분해 게시합니다.

---

## 🔔 리셋 예고

전체 사용량 리셋을 예고하는 명시적인 공지가 감지되었습니다.

**적용 완료는 아직 확인되지 않았습니다.**

게시/기록 시각: 2026-10-14 10:00 KST

영어 근거: A global reset will arrive tomorrow.

위 시각은 기록 시각입니다. `tomorrow`는 게시자 기준이며 한국의 내일과 같다고 확정하지 않습니다.

---

## ✅ 리셋 완료

추적 서비스가 전체 사용량 리셋 완료를 기록했습니다.

**본인 계정의 실제 사용량도 확인하세요.**

게시/기록 시각: 2026-10-14 11:00 KST

영어 근거: A usage refresh has been verified by the tracker.

---

## 🎟️ 초기화권 지급 안내

저장해 두었다가 사용하는 초기화권 소식입니다.

상태: **추적 서비스에서 지급 확인**

자동 리셋 완료와는 별개이며, 본인 계정에서 지급 여부를 확인하세요.

게시/기록 시각: 2026-10-14 11:30 KST

영어 근거: An additional banked reset is available to eligible accounts.
